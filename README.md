# ハチワレ手帳

ハチワレ手帳は、日々の記録や予定、習慣、集めた写真をまとめる無料のデジタル手帳です。非公式の個人制作アプリです。

- 公開ページ: <https://ginji001.github.io/hachiware-techo/>
- ログイン・アカウント登録は不要です。
- 日記、予定、リスト、写真・動画は利用中の端末のブラウザ内（IndexedDB）に保存されます。
- 記録やメディアをアプリのサーバーへ送信しません。端末やブラウザを変えても自動同期されないため、設定からバックアップを書き出して移してください。
- 利用は無料です。

## 主な機能

- デイリー: メモ、タスク、予定、気分、感謝、振り返り
- マンスリー: 月表示の予定管理、任意のGoogleカレンダー追加
- INBOX: メモやタスクの整理と、写真・動画の添付
- ハビット: 習慣と日ごとの達成記録
- コレクション、ほしい物リスト、モニター
- ガイド、プライバシー、PWAインストール、設定
- 写真・動画込みのJSONバックアップの書き出しと読み込み

マンスリーでGoogleカレンダーへの追加を選ぶと、予定の日時・タイトル・場所を含むURLをGoogleの追加画面へ渡します。既定ではこの設定はオフです。

## データとバックアップ

アプリのデータベース名と保存キーは `hachiware-techo` で始まります。メディアの実体もIndexedDBに保存し、書き出しJSONに含めます。使える容量は端末やブラウザの仕様に左右されます。ブラウザのサイトデータを削除すると記録も消えるため、定期的にバックアップを保管してください。

「バックアップを読み込む」は現在の端末内データを読み込んだ内容に置き換えます。バックアップJSONには個人の記録や写真が含まれるため、取り扱いに注意してください。

## 開発

Node.js 22.13以降が必要です。

```sh
npm ci
npm run dev
```

静的ファイルを生成し、テストを実行します。

```sh
npm test
```

本番用の静的ファイルは `out/` に出力されます。GitHub Actions は `main` へのpush時に検証・ビルドしてGitHub Pagesへ公開します。Next.jsの `basePath` として `/hachiware-techo` を設定しています。

Playwrightの主要画面スモーク確認は、環境変数 `PLAYWRIGHT_MODULE_PATH` にPlaywrightのモジュールパスを指定して `node tests/playwright-smoke.mjs` を実行します。
